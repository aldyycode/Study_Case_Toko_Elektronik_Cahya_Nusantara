# Analisis Penjualan Toko Elektronik Cahya Nusantara - Excel

Analisis Penjualan Toko Elektronik menggunakan Microsoft Excel bertujuan untuk mengevaluasi performa penjualan pada Toko Elektronik Cahya Nusantara dari Januari 2023 sampai Januari 2025. Proses analisis berfokus pada penjualan dari tiap produk, performa penjualan dari tiap kategori produk, serta mengidentifikasi top 5 sales berdasarkan kontribusi penjualan produk. Proyek ini terdiri dari beberapa proses diantaranya data cleaning, data processing, dan data visualization, dengan output berupa dashboard interaktif.

---
# Data Attributes

1. ID : Identitas unik untuk setiap transaksi.
2. Nama Kasir : Nama kasir yang menangani transaksi.
3. Kode Produk : Kode unik yang digunakan untuk mengidentifikasi produk.
4. Nama Produk : Nama produk yang dibeli oleh pelanggan.
5. Harga Satuan : Harga untuk satu unit produk.
6. Kategori : Kategori atau kelompok produk yang dibeli.
7. Tanggal Beli : Tanggal saat transaksi pembelian dilakukan.
8. Quantity : Jumlah unit produk yang dibeli dalam satu transaksi.
9. Total Harga : Total harga produk sebelum diskon.
10. Member : Status pelanggan sebagai member atau non-member.
11. Status Diskon : Menunjukan apakah transaksi mendapatkan diskon atau tidak.
12. Nominal Diskon : Besarnya potongan harga yang diberikan.
13. Total Bayar : Jumlah akhir yang harus dibayar setelah diskon.
